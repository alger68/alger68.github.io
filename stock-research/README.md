# 選股研究工作台 v2.1

GitHub Pages 官方資料接入版。公司品質、價格與研究條件分開呈現，保留資料缺口與反證。

## 開啟

部署路徑：`https://alger68.github.io/stock-research/`。亦可下載此資料夾，以瀏覽器開啟 `index.html`，不依賴外部字型或前端套件。

## 使用

1. 在「研究工作台」輸入公司名称或代號，如研華、2395、0050。
2. 點選結果，建立「我的研究」卡片，自動上網讀取官方盤後行情、月營收及一般業財報摘要。已存在的研究卡開啟時也會補資料。
3. 在「證據與反證」記錄原始連結、日期、主張與定位，另可保存研究筆記。
4. 在「分析法」選自動建議或手動，依研究目的保存設定。
5. 在「估值試算」輸入同期間的假設 EPS 和 PE；ETF 使用獨立說明。
6. 按「上網更新」讀取網站最近成功抓取的官方資料；完成後畫面自動更新。「整理筆記」只處理已保存筆記。新資料會解除舊版確認，不會自動寫 Notion。
7. 暫停與移除可以復原；篩選「已暫停」或「已移除」即可管理。
8. 使用「匯出我的研究」下載 JSON 備份。本版還沒有匯入／還原介面。

## 資料與保存

- 名稱目錄沿用原股票工作台的 2026-10-05 公開資料快照，共 1,988 筆（上市 1,095、上櫃 892、ETF 0050 一筆）。不是全部 ETF 目錄，也不是即時交易狀態。
- 目錄来源：TWSE OpenAPI `t187ap03_L`、TPEx `mopsfin_t187ap03_O`、TWSE 0050 ETF 商品頁。完整來源列在 `directory.js`。
- 個人研究用 localStorage 保存；與原 Sites／Notion 清單分開。瀏覽器清除資料、換裝置或私密視窗可能造成資料不可用，請匯出備份。
- 使用者輸入不寫回 GitHub，公開儲存庫沒有你的研究清單與筆記。瀏覽器本機保存不是加密保管庫；相同網站 origin 下的其他程式也受同源規則影響。
- 假設案例全部虛構，只供看版型及驗算；不是市場建議。對真實公司的來源筆記屬人工輸入，未自動查核。
- 多分頁編輯會提示重新載入；請避免同時編輯同一研究資料。

## 功能邊界

已實作：搜尋、清單、篩選、方法設定、筆記、來源、估值假設、算式、版本、已閱確認、暫停／移除／復原、JSON 匯出。

已接入：官方盤後價格、月營收、歷史 PE／PB 與一般業財報摘要；其他業別或未取得的來源留缺口。

尚未接入：盤中即時行情、完整現金流研究、KOL 原文抓取、完整 SEPA／VCP、全市場回測、私人資料跨裝置同步與 Notion。已取得資料不等於買進條件成立。

Marks 的風險立場與股價方向分开；MANUS 是證據整理流程，不是外部服務或第七份獨立利多。研究狀態不採七法多數票。

## 結構與驗證

- `index.html`：頁面骨架及 metadata。
- `style.css`：響應式工作台版面。
- `directory.js`：公開公司身分資料。
- `engine.js`：資料門檻、選法、搜尋與估值純函式。
- `app.js`：互動、本機紀錄與頁面。
- `tests/engine.test.cjs`：核心規則回歸測試，執行 `node --test stock-research/tests/engine.test.cjs`。

正式後端應採用不可變 research snapshot、來源日期、確認 hash、同步佇列與寫入後讀回。詳細方法與可行性由另附的 v2.1 規格說明；未將原私人文件及其帳戶脈絡公開到本儲存庫。

## 官方資料更新方式

公開資料收集工作流程在台灣時間每日 07:20、平日 14:20 執行，另可在 GitHub Actions 手動啟動；排程可能排隊，以資料來源擷取時間為準。工作流程自動從 TWSE／TPEx 官方公開 API 取得整體市場資料，發布到 `data/market.json`。個人追蹤名單不傳到工作流程。

前端「上網更新」使用 no-store 請求讀取網站目前最新成功快照，不是即時強制交易所或 GitHub 工作流程重新抓取。這樣可避免手機受交易所跨來源讀取限制。行情日期、營收月份、財報期別和擷取時間分開顯示；過期或失敗不改成今日數字。

財報摘要保留來源季別，單季／累計口徑尚未核定前不年化 EPS、不計算成長率、不冒充前瞻 EPS。所得 PE 是來源當日歷史本益比，不拿當季 EPS 倒推。

來源某個模組失敗時保留該模組前版；前端亦防止較舊資料覆蓋較新期別。市場身分以交易所及代號一起匹配。ETF 不混入公司財報。

新增檔案：`market.js` 負責驗證與正規化、`online-ui.js` 負責上網更新與呈現、`scripts/collect-market.mjs` 負責官方資料收集、`tests/market.test.cjs` 負責資料邊界測試。
