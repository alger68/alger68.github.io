## Decisions / Rulings
- TPEx history must not report `ready` merely because the code exists. It is `configured` until a real request returns parsed rows.
- Official latest-day OpenAPI and monthly-history endpoint are separate contracts; do not treat `tpex_mainboard_daily_close_quotes` as history.
- `N/A`, blank, `-`, and non-numeric valuation markers remain missing, never coerced to zero.
- The project environment cannot reach `tpex.org.tw` directly due DNS/network restrictions; therefore live upstream proof must come from the user's Taiwan Mac via `Check_TPEx.command` before PR #4 leaves Draft.

## Known Issues
- Live 6488 TPEx upstream output has not yet been observed in this execution environment.
- Cash flow/FCF remains a separate 15.4C item; this audit does not claim TPEx cash flow is production-ready.
- Recent general news is not an official TPEx market-data source; official重大訊息 remains separate from general-news aggregation.
