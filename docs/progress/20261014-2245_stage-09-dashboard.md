# StockMaster V3.1 Stage 09 — Full 1–10 Dashboard Frontend

## Status
Complete

## Goal
建立對應需求圖的桌機/手機 1～10 區 Dashboard，前端只吃 FastAPI JSON，並明確顯示 stale quote。

## Completed
- 建立 Dashboard presentation model。
- 建立 API client / state / controller / lightweight chart renderer。
- 建立 1～10 區塊：搜尋、Quick Cards、股價/技術、基本面、技術指標、新聞、財報、自選股、市場總覽、Decision。
- stale quote 顯示黃色警示、`昨日收盤`、行情日期、系統檢查時間。
- 缺資料使用 `—` / null，不轉成 0。
- 建立響應式版面；手機隱藏側欄且禁止整頁橫向捲動。
